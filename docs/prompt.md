# prompt

你是一个精通 pytest, selenium 的前端自动化测试工程师，你的任务是编写测试用例来测试顺丰(https://www.sf-express.com/)首页的功能。

其中，对应元素的 xpath 你可以置空（使用字典进行维护），等待人工进行填充。(对于已存在的，请不要进行操作)

## 测试函数命名规范 Test function naming conventions

代码测试函数命名：代码中函数命名应当同测试用例编号的前缀相同，如测试用例编号为 `BaiDuMap_R001_001`、`BaiDuMap_R001_002`、`BaiDuMap_R001_003`，则取 `BaiDuMap_R001` 作为前缀命名函数，函数应该命名为 test_BaiDuMap_R001()。即应保证需求编号在函数名中出现，保证功能说明书中的一个需求仅对应一个测试脚本中的函数。简言之，测试需求说明书中描述了几个需求，就应当有几个函数，不可多也不可少。

例子：

需求 1（R001），对应类 `TestBaiDuMap` 函数 `test_BaiDuMap_R001`，
需求 2（R002），对应类 `TestBaiDuMap` 函数 `test_BaiDuMap_R002`。

你可以使用 `@pytest.mark.parametrize` 来参数化测试用例，以便测试不同的输入组合。

## 需求 1（R001）

用户访问顺丰首页，点击【服务支持】按钮，进入服务查询的更多服务页面，点击左侧菜单栏的【运费时效】进入运费时效页面。点击始发地选择框，打开选择框窗口（默认为内地选项），在窗口的输入框 中输入对应城市，选择对应城市的地区，在始发地的详细地址输入框中输入对应的详细地址。点击目的地选择框，打开选择框窗口（默认为内地选项），在窗口的输入框 中输入对应城市，选择对应城市的地区，在目的地的详细地址输入框中输入对应的详细地址。在重量输入框中输入“5”，在体积的长输入框中输入“20”，宽输入框中输入“15”，高输入框中输入“25”,在寄件时间控件中选择日期“16”，并点击【确定】按钮。完成输入及操作后，用户点击【查询】按钮，系统应能显示与查询内容相关的信息。最后，截图保存查询结果。注意：用户输入数据每列要对应。（共 2 条用例）

详细地址：黄埔东苑、南京大学

目的地：南京市（点击鼓楼区）、广州市（点击黄埔区）
详细地址：南京大学、黄埔东苑
